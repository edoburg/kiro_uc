# LINE Creators Market アップロード手動確認

最終更新: 2026-09-28

この機能は LINE Creators Market の公開 API ではなく、Playwright でブラウザを操作します。画面仕様の変更、2段階認証、CAPTCHA、規約同意が発生し得るため、実アカウントを使う確認は次の手順で安全に行います。

> **保留中:** ログイン後の画面遷移と登録操作を安定して自動化できなかったため、現在は `src/config/features.ts` の `LINE_CREATORS_UPLOAD_ENABLED = false` により関連UIを非表示にしています。バックエンドとテストは将来の再検討に備えて残しています。

## 現在の安全設定

- Chromium は画面を表示して起動します（`headless=False`）。
- 既定動作は下書き保存までです。
- 審査申請ボタンは既定では押しません（`submit_for_review=False`）。
- LINEメールアドレスとパスワードは OS Keychain に別々に保存し、Config、ログ、設定エクスポートには含めません。
- 追加認証画面が表示された場合は最大2分間、可視ブラウザ上での手動操作を待ちます。

## 事前準備

1. Python依存関係をインストールします。
2. 開発環境で初回のみ `playwright install chromium` を実行します。
3. 審査申請しても問題のないテスト用画像ではなく、まず「下書き保存だけ」を確認できるセットを用意します。
4. 設定画面で LINEメールアドレスとLINEパスワードを保存します。

## 確認手順

1. 8枚の画像を生成・変換します。
2. タイトル、説明、クリエイター名、コピーライトを入力します。
3. 「アップロードする」を押します。
4. 表示された Chromium で2段階認証、CAPTCHA、規約同意が求められた場合だけ手動で完了します。
5. 新規登録、スタンプ情報入力、スタンプ画像・メイン画像・トークルームタブ画像の選択を目視します。
6. 完了画面が「LINE Creators Marketに下書きを保存しました。」になり、ステータスが `draft` であることを確認します。
7. LINE Creators Market のマイページを手動で開き、下書きだけが作成され、審査申請されていないことを確認します。

## 失敗時の確認箇所

- `auth`: メールアドレス、パスワード、追加認証、セッション切れを確認します。値自体はログに出ません。
- `network`: 通信状態を確認します。5秒間隔で最大3回リトライします。
- `validation`: LINE側の画面変更または不足項目の可能性があります。エラーメッセージに示された入力欄・ボタンを実画面と比較します。
- `unknown`: PlaywrightとChromiumのバージョン、バックエンドログを確認します。

## 実画面確認後の記録

次を確認できた場合だけ `TASKS.md` の T-013 を完了にします。

- ログイン後の新規登録ボタンとスタンプ選択が動作する。
- タイトル、説明、クリエイター名、コピーライトが入力される。
- 8枚以上のスタンプ画像、メイン画像、トークルームタブ画像が登録される。
- 下書き管理IDを取得できる。
- 審査申請が送信されていない。

管理画面のセレクターが変わっていた場合は `backend/services/uploader_service.py` の候補セレクターを更新し、モックテストを追加してから再確認します。
