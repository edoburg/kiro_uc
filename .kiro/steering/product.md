# プロダクト: LINEスタンプジェネレーター

日本語ユーザーが自然言語のプロンプトからLINEスタンプセットを生成し、LINE Creators Marketへ直接アップロードできるローカルデスクトップアプリケーション。デザインスキル不要。

## コアユーザーフロー

1. ユーザーが日本語または英語でキャラクターの外見・画風の共通設定を入力し、テーマ・枚数・スタイル・生成モードを選ぶ
2. 定型リストから指定枚数分の企画を作成し、言葉／意味・表情・ポーズ・小物を編集する。画像生成はこの段階では開始しない
3. 企画を確定してから、AIが各項目の設定を使って指定枚数（8/16/24/32/40枚）のスタンプ画像を生成する
4. アプリがLINE規格（サイズ・フォーマット・ファイルサイズ）に自動変換する
5. ユーザーがプレビューで確認・編集し、必要に応じて個別画像を差し替える
6. アプリが完成したスタンプセットをLINE Creators Marketへアップロードする

## 主なユーザー

デザインの専門知識を持たない、LINEスタンプを販売・公開したい日本語話者のクリエイター。

## 主な制約

- ユーザー向けのテキストおよびエラーメッセージはすべて**日本語**で記述する
- Windows / macOS / Linux のローカル環境で動作すること
- LINE規格のバリデーションを通過するまでアップロードを許可しない
- APIキーおよび認証情報は平文で保存しない
